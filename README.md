# Travel Sauce 🗺️

Places I've been. Things worth going back for.

**Live:** [henrysommer.de/travel-sauce](https://henrysommer.de/travel-sauce)

## What is this?

A personal travel recommendations page. No sponsored content, no affiliate links – just places I've actually been and things that were genuinely worth it.

Structured by country → city → spot, with direct links to Google Maps, Hostelworld, etc.

## Currently

🇲🇦 **Morocco** – Marrakesh, Imsouane, Taghazout, Tamraght

More countries coming as I travel.

## Stack

Static HTML/CSS/JS. Same design system as [henrysommer.de](https://henrysommer.de) – DM Sans + DM Serif Display, warm off-white palette. Custom accordion UI for countries.

## Highlights so far

- **Hostel Riad Rouge** (Marrakesh) – best hostel social vibe I've experienced
- **Mish Mish Café** (Tamraght) – second best espresso of my life
- **The Wedge** (Taghazout) – a hidden oasis, could stay all day
